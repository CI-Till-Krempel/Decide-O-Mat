# Announcing Decide-O-Mat v2.0: Instant QR Code Sharing, Mobile-First Navigation & Repository Hardening

We are thrilled to announce the official release of **Decide-O-Mat v2.0** — our biggest major milestone yet! This release transforms Decide-O-Mat into a universal, frictionless, privacy-preserving decision platform built for instant in-person, hybrid, and mobile collaboration.

---

## 🚀 What's New in v2.0?

### 1. Instant QR Code Sharing (US-037, #458)
Sharing decisions in meetings, workshops, and gatherings is now effortless:
- **Client-Side High-Contrast QR Codes**: Instantly generate clean, scannable QR codes for any decision directly in your browser.
- **Full E2EE Preservation**: Encryption keys stored in URL hash fragments (`#key=...`) are preserved end-to-end so that scanning participants decrypt the decision instantly and privately.
- **Speed-Dial Action Menu**: The floating action button now features an expandable menu with direct options for **Copy Link** and **Show QR Code**, plus PNG image downloads and clipboard fallback.

### 2. First-Class Mobile & Responsive Experience (US-038, #459, #460)
Decide-O-Mat is now completely optimized for smartphones, tablets, and small screens:
- **Mobile Navigation Drawer**: A clean hamburger menu in the header gives mobile users instant access to "Decision" and "Activities" (`/my-decisions`).
- **Zero-Overlap Safe Padding**: Action buttons (QR code, statistics, participants) now live in dedicated safe areas above the decision title, eliminating overlapping text on small viewports.
- **Instant Top-Level Participants Access**: Directly inspect voters and participants from the hero header without scrolling through long argument lists.
- **Touch Targets & Keyboard Optimization**: Full support for 44px minimum tap targets, safe-area insets (`env(safe-area-inset-bottom)`), and responsive columns down to 320px screen width.

### 3. Comprehensive Data Integrity & E2EE Key Sync Hardening (#407, #408, #413, #414)
- **Automatic Key Recovery**: Decision views now transparently recover encryption keys from local storage on direct links, page refreshes, and bookmark visits.
- **Magic Link Key Transfer**: Transferring anonymous identities across devices seamlessly transfers decision encryption keys.
- **Secure Token Cleanup**: Magic link authentication tokens are immediately removed from the browser history and address bar upon consumption.
- **Real-Time Vote Syncing**: User votes synchronize directly with Firestore subcollections with optimistic UI fallback.

### 4. Privacy, GDPR Compliance & Internationalization (#410, #416, #417)
- **100% Self-Hosted Fonts**: Google Fonts are bundled and served locally, eliminating third-party tracking and ensuring strict GDPR compliance.
- **Bilingual Interface (EN / DE)**: Full localization across all views with a top-level language switcher control.
- **Profile Self-Service**: Edit display names, review email addresses, and trigger password resets from your profile settings.
